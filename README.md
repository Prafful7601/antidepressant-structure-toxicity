# Structure-Toxicity Analysis of Antidepressants

Repository: https://github.com/Prafful7601/antidepressant-structure-toxicity

Author: Prafful Gupta (first author)

Two linked analyses, both reproducible from this repository:

1. **Pharmacovigilance (FAERS) + cheminformatics** (RDKit/ChEMBL/PubChem) --
   root-level scripts, below -- linking antidepressant chemical structure to
   organ-system toxicity signals derived from spontaneous adverse-event
   reports, with a structure-based Toxicity Risk Score (TRS) validated by
   leave-one-drug-out cross-validation.
2. **MIMIC-IV clinical validation** (`mimic4_pipeline/`) -- tests whether
   the FAERS-derived organ-toxicity signals from (1) are measurable in real
   hospital admissions: antidepressant exposure classification, hepatic and
   sodium outcome extraction, and a Tricyclic-vs-SSRI/SNRI comparison at
   three progressively rigorous layers (unadjusted, comorbidity-adjusted,
   propensity-score-matched). See `mimic4_pipeline/README.md` for that
   pipeline's own detailed documentation, task-by-task.

This repository holds the reproducible analysis code (+ data + figures for
the FAERS/cheminformatics side; MIMIC-IV's own outputs are gitignored per
its data use agreement, see `mimic4_pipeline/README.md`) behind two
manuscripts. **The manuscripts themselves are kept out of this public repo
to avoid pre-disclosing unpublished results ahead of submission** (drafts,
results/summary write-ups, figure-generation scripts for the manuscripts,
and their `.docx` generator scripts); they are maintained locally alongside
this repo and regenerated from the same CSVs/pipeline outputs the public
code produces. What follows is a description of each manuscript's *scope*
(what data it draws from, what it covers, what its figures show
methodologically) -- not its findings.

- **`Research_Paper.docx`** (generator: `make_paper.py`, not in this repo):
  the FAERS/cheminformatics analysis alone -- disproportionality signals
  across the 28-drug curated set, within-class safety ranking,
  structure-toxicity correlation with FDR correction, the TRS and its
  in-sample-vs-cross-validated comparison, and ChEMBL candidate screening.
  Figures (`charts/*.png`, generated by `make_charts.py`, tracked in this
  repo): a TRS in-sample-vs-LOOCV validation scatter, a per-drug/organ ROR
  heatmap, fitted TRS feature weights, a per-drug toxicity-index comparison
  by class, and structural-feature effect direction by organ system.
- **`Antidepressant_Organ_Toxicity_Unified_Study.docx`** (generator:
  `make_final_paper.py`, not in this repo): the full combined manuscript --
  everything in `Research_Paper.docx` above (Part A), plus the MIMIC-IV
  validation (Part B: cohort construction, the primary Tricyclic-vs-SSRI/
  SNRI comparison, pre-specified clinical thresholds, severity adjustment,
  and the propensity-matched sensitivity analysis), in one flowing
  narrative with a single Discussion connecting both parts. Figures
  (`mimic4_charts/*.png`, generated by `make_mimic4_charts.py`, tracked in
  this repo but the rendered PNGs are gitignored -- see
  `mimic4_pipeline/README.md`'s data-use-agreement rationale): a cohort
  construction flow diagram, a covariate-balance ("Love") plot for the
  propensity match, and a forest plot comparing effect sizes across the
  three analytic layers, per outcome. This is the current, most complete
  manuscript.

## Pipeline (run in this order)

1. `fetch_faers_openfda.py` - pulls FAERS adverse-event reports from the
   openFDA API for all 28 drugs -> `faers_reports.csv`. (Optional:
   `topup_faers.py` to re-fetch any drug truncated by a transient network
   error.) **Slow / network-bound; `faers_reports.csv` is already included so
   you don't have to re-run this to reproduce downstream results.**
2. `faers_disproportionality.py` - ROR/PRR/IC disproportionality per
   drug x organ system -> `faers_signals.csv`.
3. `rank_within_class.py` - within-pharmacological-class safety ranking ->
   `class_safety_ranking.csv`.
4. `cheminformatics_analysis.py` - RDKit descriptors/substructure flags,
   structure-toxicity correlation (Fisher + Mann-Whitney, both with
   Benjamini-Hochberg FDR correction), and structural-feature
   multicollinearity check -> `drug_features.csv`,
   `structure_toxicity_correlation*.csv`,
   `structural_feature_multicollinearity*.csv`.
5. `fit_trs.py` - fits the Toxicity Risk Score and validates it both
   in-sample (circular) and by leave-one-drug-out cross-validation (honest)
   -> `trs_weights.csv`, `drug_trs.csv`, `trs_loocv.csv`.
6. `chembl_candidate_screen.py` - screens ChEMBL for novel candidate
   molecules (Tanimoto novelty, Lipinski/Veber/Ghose, ChEMBL approval-status
   overlap check) -> `chembl_candidates_screened.csv`.
7. `sensitivity_moclobemide.py` - sensitivity analysis re-running the
   structure-toxicity correlation and TRS fit/LOOCV with moclobemide
   excluded -> `sensitivity_excl_moclobemide.csv`.
8. `pubchem_verify.py` - independently verifies all 28 curated SMILES against
   PubChem by InChIKey skeleton -> `pubchem_verification.csv`.
9. `faers_date_range.py` - determines the actual FAERS receive-date range
   captured and dumps the exact openFDA query string per drug ->
   `faers_date_range.csv`, `faers_query_strings.txt`.
10. `sanity_check.py` - independently re-derives key statistics directly from
    raw data and flags any inconsistency with the pipeline's own outputs.
11. `make_charts.py` - generates all figures (`charts/*.png`) from the CSVs
    above; this is the single source of truth for every chart, including
    those used in the (locally-maintained, not published here) manuscript.

Every script reads its inputs from CSVs in this directory and is safe to
re-run independently once its upstream CSVs exist. The manuscript's own
`.docx` generator scripts are not part of this repo (see above) but consume
exactly the CSVs and charts produced by the steps above.

## MIMIC-IV validation pipeline

`mimic4_pipeline/` is a separate, self-contained sub-project (its own
`pyproject.toml`, `README.md`, `sql/`, `src/`, `tests/`) with its own
reproduction steps -- see `mimic4_pipeline/README.md` for the full,
task-by-task walkthrough (database build and validation, antidepressant
exposure mapping, cohort construction, outcome extraction, severity
adjustment, the statistical comparison, and the propensity-score-matched
sensitivity analysis), including exact commands to run every stage and a
day-one feasibility check (`scripts/day_one_counts.py`) meant to be run the
moment full MIMIC-IV access is granted. It shares the 28-drug curated
antidepressant list with the FAERS/cheminformatics pipeline above but is
otherwise independent -- different data source, different codebase,
different license considerations (MIMIC-IV requires its own PhysioNet
credentialing; see that README's "No patient data" section).

## Key methodological notes

- **Primary disproportionality signal**: ROR lower 95% bound > 2 and >= 3
  cases (standard pharmacovigilance practice). The more permissive legacy
  ROR>1 criterion is retained only as a supplementary comparison
  (`signal_ror1` column in `faers_signals.csv`) and is not used for any
  headline result.
- **Multiple testing**: all structure-toxicity tests (4 organ systems x 16
  structural features) are corrected with Benjamini-Hochberg FDR; see the
  `p_adj_bh` / `significant_fdr05` columns.
- **TRS validation**: `drug_trs.csv` and `trs_loocv.csv` report both the
  in-sample fit (circular - weights are derived from the same drugs) and the
  leave-one-drug-out cross-validated prediction (honest). Report both
  together; never the in-sample number alone.
- **Clorgyline** is in the curated 28-drug structure set but was never
  marketed and returned zero FAERS reports, so it is excluded from all
  FAERS-dependent analyses (27 drugs with data).

## Data availability

FAERS data are retrieved from the public [openFDA API](https://open.fda.gov)
with no API key required; the exact query string used for every drug is in
`faers_query_strings.txt`, and the effective date range retrieved is in
`faers_date_range.csv`. ChEMBL and PubChem data are retrieved from their
respective public REST APIs. All intermediate and final CSVs referenced above
are included in this repository so the full analysis can be reproduced
without re-querying any external API.

MIMIC-IV data availability is handled separately, under a different license
regime -- see `mimic4_pipeline/README.md`'s "No patient data in this
repository" section. In short: the open, ODbL-licensed MIMIC-IV demo needs
no credentialing and is what this repo's own tests run against; the full
MIMIC-IV database used for the actual reported results requires independent
PhysioNet credentialing and a signed data use agreement, and is not
distributed by this project in any form.
